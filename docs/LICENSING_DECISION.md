# License decision required from rights holders

The manuscript's author list and software citation identify scholarly
attribution; they do **not** specify the copyright owners' permission to
redistribute or modify the project. Therefore this packaging update does not
select an open-source license on the authors' behalf.

Before presenting the repository as open source, the appropriate rights
holders should confirm an explicit license for the original code and any
research materials they own (for example, an OSI-approved software license
chosen with their permission). Third-party raw datasets, pretrained models,
adapters derived from restricted models, figures and other separately owned
materials retain their own licenses and access restrictions.

Once authorized, add the exact approved `LICENSE` text at the repository
root, and update the README with any distinct data/model licensing notices.
Absent that authorization, publish only if permitted and describe the release
as publicly viewable research materials, **not** as automatically open source.
